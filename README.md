# Superstore-Sales-PowerBI-Analysis
Interactive Superstore Sales &amp; Profit Analysis Dashboard using Microsoft Power BI
## 📌 Project Overview
This project presents an interactive Sales and Profit Analysis Dashboard developed using Microsoft Power BI.
The objective of this project is to transform raw Superstore sales data into meaningful business insights by performing data preparation, analysis, KPI development, and interactive data visualization.
The dashboard provides an overview of sales performance, profitability, customer segments, product performance, shipping modes, and regional trends.
## 🎯 Business Objective

The primary objective of this project is to analyze sales and profitability data and answer important business questions such as:

- How are sales and profit performing over time?
- Which product sub-categories generate the highest sales?
- Which products contribute the most to profitability?
- Which products or sub-categories are loss-making?
- Which customer segment contributes the highest sales?
- Which shipping mode generates the highest sales and profit?
- Which states and regions perform best?
- Where are there opportunities to improve profitability?
